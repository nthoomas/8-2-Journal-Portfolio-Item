8-2 Journal: Portfolio Item

How can I ensure that my code, program, or software is functional and secure?
I can ensure my code, program, or software is functional and secure by making sure to follow best practices when coding, meeting the requirements, and testing throughout development.

How do I interpret user needs and incorporate them into a program?
I can interpret user needs by understanding what is expected of me early on, then following those requirements throughout development, ensuring that what they want and need are being put forth while developing. Never be afraid to ask too many questions, then break that down from an idea into a roadmap on how to achieve it.

How do I approach designing software?
You should always approach designing software by making sure you are first reviewing the requirements set forth by the customer, then, 
like I said above, breaking it down into smaller, achievable parts, making sure not to overcomplicate things as you develop.
